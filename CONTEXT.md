# Nail Polish Collector

A multi-user web app (phone-friendly views, usable on desktop too) where each user records which nail polishes they physically own and where they are stored.

## Language

**Polish**:
A named product (brand + shade name), including base coats, top coats and similar. Existing as a Polish implies nothing about ownership or store availability.
_Avoid_: Shade, product, SKU

**Private Polish**:
A Polish created by a User that only that User can see, for shades no Vendor sells (limited-edition sets, discontinued, indie). The Admin may promote it to the public Catalog.
_Avoid_: Custom polish, user polish

**Bottle**:
A specific physical container of a Polish that one User owns, with a Location and a Status.
_Avoid_: Item, unit, copy

**User**:
A person with their own account and their own collection of Bottles.
_Avoid_: Customer, member

**Collection**:
The set of Bottles owned by one User. Searching "what I own" only ever reports on the current User's Collection.
_Avoid_: Inventory, stash

**Catalog**:
The public, shared set of all known Polishes, readable by anyone and editable only by the Admin. Populated by importing from Vendor sites.
_Avoid_: Database, library

**Admin**:
A role that may edit the Catalog, promote Private Polishes, and trigger an Import from a Vendor. Initially one person; the role can be granted to others.
_Avoid_: Owner, moderator

**Import**:
An Admin-triggered pull of a Vendor's current Polishes (with images) into the Catalog, e.g. on a launch day.
_Avoid_: Sync, scrape, crawl

**Vendor**:
A remote store that sells Polishes; a Polish may link to the Vendor's page for it.
_Avoid_: Store, retailer, shop

**Discontinued**:
A Polish whose Vendor link no longer shows it for sale; the User is told this when viewing the Polish. Discontinued Polishes go on a Watchlist and are re-checked at decreasing frequency.
_Avoid_: Unavailable, out of stock

**Watchlist**:
The set of Discontinued Polishes that are periodically re-checked in case a Vendor restocks them.
_Avoid_: Discontinued list

**Location**:
A user-defined, free-named place where a Bottle is kept (e.g. "dining room", "under the bed, holo taco tray").
_Avoid_: Storage, shelf

**Status**:
A Bottle's lifecycle state: owned, used up, given away, or discarded. Non-owned Bottles remain as history.
_Avoid_: State, condition

**Finish**:
A Polish's surface effect (creme, shimmer, glitter, holographic, matte, jelly, ...); a Polish may have several.
_Avoid_: Type, effect

**Color family**:
The single coarse color group a Polish belongs to (red, pink, nude, ...).
_Avoid_: Color, hue

**Swatch photo**:
An image of a Polish, initially pulled from the Vendor's site.
_Avoid_: Picture, thumbnail

**Self-signup**:
Creating an account with just an email address and a magic link, no Invite code. Available only for the first 100 Users; after that, signup is by Invite code only.
_Avoid_: Registration, open signup

**Invite code**:
A single-use code generated by the Admin for a specific email address; creates a User account once self-signup has closed. Unlimited in number.
_Avoid_: Token, voucher

**Manicure**:
A User's photographed set of nails, labeled with the Polishes worn. Public by default; the owning User may make it private.
_Avoid_: Look, post, nail art

**Heart**:
A User's one-per-Manicure favorite mark on someone else's public Manicure. Saves it to their Liked list and counts toward the Gallery's "most loved" sort.
_Avoid_: Like, upvote, vote

**Gallery**:
The searchable, filterable browse of all public Manicures, sortable by newest or most hearted.
_Avoid_: Feed, timeline

**Invite request**:
An email address submitted on the signup page after Self-signup has closed, so the Admin can decide whether to send an Invite code.
_Avoid_: Waitlist entry
