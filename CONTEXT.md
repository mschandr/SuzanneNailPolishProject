# Nail Polish Collector

A multi-user web app (phone-friendly views, usable on desktop too) where each user records which nail polishes they physically own and where they are stored.

## Language

**Polish**:
A named product (brand + shade name), including base coats, top coats and similar. Existing as a Polish implies nothing about ownership or store availability.
_Avoid_: Shade, product, SKU

**Private Polish**:
A Polish created by a User that only that User can see, for shades no Vendor sells (limited-edition sets, discontinued, indie). The Admin may promote it to the public Catalog.
_Avoid_: Custom polish, user polish

**Bottle**:
A specific physical container of a Polish that one User owns, with a Location and a Status.
_Avoid_: Item, unit, copy

**User**:
A person with their own account and their own collection of Bottles.
_Avoid_: Customer, member

**Collection**:
The set of Bottles owned by one User. Searching "what I own" only ever reports on the current User's Collection.
_Avoid_: Inventory, stash

**Catalog**:
The public, shared set of all known Polishes, readable by anyone and editable only by the Admin. Grows by the Admin adding Polishes, by Import, and by promoting Private Polishes.
_Avoid_: Database, library

**Admin**:
A role that may edit the Catalog, run an Import, promote Private Polishes, moderate Manicures, suspend Users and send Invite codes. Initially one person; the role can be granted to others.
_Avoid_: Owner, moderator

**Import**:
The Admin adding many Polishes to the Catalog from a CSV file they supply, after previewing it and ticking what to add. Existing Polishes are never changed. Nothing is fetched from any Vendor's site, because no Vendor's terms allow it.
_Avoid_: Sync, scrape, crawl, pull

**Vendor**:
A remote store that sells Polishes; a Polish may link to the Vendor's page for it. The app does not read from Vendors.
_Avoid_: Store, retailer, shop

**Discontinued**:
A Polish whose Vendor link no longer shows it for sale; the User is told this when viewing the Polish. Discontinued Polishes go on a Watchlist and are re-checked at decreasing frequency. (Planned, not built: it needs a Vendor's written permission to check its pages.)
_Avoid_: Unavailable, out of stock

**Watchlist**:
The set of Discontinued Polishes that are periodically re-checked in case a Vendor restocks them.
_Avoid_: Discontinued list

**Location**:
A user-defined, free-named place where a Bottle is kept (e.g. "dining room", "under the bed, holo taco tray").
_Avoid_: Storage, shelf

**Status**:
A Bottle's lifecycle state: owned, used up, given away, or discarded. Non-owned Bottles remain as history.
_Avoid_: State, condition

**Finish**:
A Polish's surface effect (creme, shimmer, glitter, holographic, matte, jelly, ...); a Polish may have several.
_Avoid_: Type, effect

**Color family**:
The single coarse color group a Polish belongs to (red, pink, nude, ...).
_Avoid_: Color, hue

**Swatch photo**:
An image of a Polish: one the Admin or a User uploaded, or a link to an image hosted elsewhere that an Import supplied (shown from its source, never copied).
_Avoid_: Picture, thumbnail

**Self-signup**:
Creating an account with just an email address and a magic link, no Invite code. Available only for the first 100 Users; after that, signup is by Invite code only.
_Avoid_: Registration, open signup

**Invite code**:
A single-use code generated by the Admin for a specific email address; creates a User account once self-signup has closed. Unlimited in number.
_Avoid_: Token, voucher

**Manicure**:
A User's photographed set of nails (up to four photos), labeled with the Polishes worn. It follows the owner's usual privacy setting unless the owner overrides it, which starts as public.
_Avoid_: Look, post, nail art

**Layer**:
One Polish listed on a Manicure, in the order applied (base coat first); the same Polish can appear twice for two coats. In whole-hand mode there is one list for the hand; in per-nail mode each of the ten nails has its own list, and the other mode's list is kept but dormant. A Layer may link to one of the owner's own Bottles.
_Avoid_: Coat, label

**Liked list**:
The public Manicures a User has hearted that are still public.

**Heart**:
A User's one-per-Manicure favorite mark on someone else's public Manicure. Saves it to their Liked list and counts toward the Gallery's "most loved" sort.
_Avoid_: Like, upvote, vote

**Gallery**:
The searchable, filterable browse of all public Manicures, sortable by newest or most hearted.
_Avoid_: Feed, timeline

**Report**:
A User's complaint about someone else's public Manicure, with a reason. Reports are reviewed only by the Admin.
_Avoid_: Flag

**Hidden**:
A Manicure the Admin has removed from every public place. Its owner still sees it with a notice, can no longer edit it, and can still delete it. The Admin can restore it.
_Avoid_: Banned, removed

**Suspended**:
A User the Admin has blocked: they cannot sign in and their public content is hidden. The Admin can lift it.
_Avoid_: Banned, deleted

**Needs review**:
A Polish added by Import without a Color family or Finish. It is listed for the Admin until both are filled in.

**Credit**:
The attribution shown with a photo someone else took and shared under an open license, with a link to its source and license.

**Featured account**:
A system account that cannot be signed into, which holds the openly licensed sample Manicures in the Gallery.

**Invite request**:
An email address submitted on the signup page after Self-signup has closed, so the Admin can decide whether to send an Invite code.
_Avoid_: Waitlist entry
