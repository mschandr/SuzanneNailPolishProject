# 01: App skeleton and deploy pipeline

**What to build:** A Laravel app on Postgres with UUID primary keys, a responsive phone-friendly layout shell and a queue runner, deployed to a DigitalOcean droplet and serving a health page (see ADR 0001).

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] App deploys to the droplet from the repo
- [ ] Health page loads on phone and desktop
- [ ] A queued test job runs
- [ ] Models use UUID keys
